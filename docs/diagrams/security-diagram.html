🔒 Zero-Trust Security & Authentication Handshake
IAM OIDC Bearer Token Verification
1
Client Authentication & Initial ID Token
Browser Client
User enters credentials on login form. Firebase Client SDK authenticates against Google Identity Platform and returns a short-lived ID token.
POST /_auth/login ➔ signInWithEmailAndPassword() ➔ idToken
2
Session Cookie Exchange via loginFn
BFF Layer
Client dispatches idToken to BFF via loginFn. Server calls Firebase Admin SDK to mint a cryptographically signed 5-day session cookie with strict security flags.
adminAuth.createSessionCookie(idToken, 5 days) ➔ Set-Cookie: session=...; HttpOnly; Secure; SameSite=Lax
3
Request Interception & Session Verification
isLoginMiddleware
Every mutating server function passes through isLoginMiddleware. It extracts the cookie, calls verifySessionCookie(session, checkRevoked: true), and binds verified claims to request context.
adminAuth.verifySessionCookie() ➔ context.userInfo { uid, email, role }
4
Google Cloud IAM OIDC Token Minting
google-auth-library
Using Application Default Credentials (ADC), the BFF requests an OpenID Connect (OIDC) ID token audience-scoped to the exact base URL of the target Cloud Run microservice.
auth.getIdTokenClient(targetUrl) ➔ OIDC ID Token [aud: targetBaseUrl]
5
Zero-Trust Microservice Invocation
Cloud Run IAM
Request is dispatched with Authorization: Bearer OIDC_TOKEN. Google Cloud IAM validates the token signature, audience, and service account invocation permissions, executing the private container.
HTTP Request [Authorization: Bearer ...] ➔ Cloud Run Ingress Validation ➔ 200 OK
