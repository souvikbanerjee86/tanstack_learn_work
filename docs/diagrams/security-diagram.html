🔒 Zero-Trust Authentication & Session Lifecycle Protocol
Multi-Phase Mermaid Sequence Architecture
● Phase 1: Authentication & Session Creation
sequenceDiagram autonumber participant User as Recruiter participant Client as Browser Client participant BFF as TanStack BFF participant Admin as Firebase Admin User->>Client: Enters credentials / SSO Client->>Client: Firebase SDK gets ID Token Client->>BFF: loginFn(idToken) BFF->>Admin: createSessionCookie(5-day) Admin-->>BFF: Signed session cookie BFF-->>Client: Set-Cookie: session (HttpOnly, Secure) Client->>BFF: getUserRole(user_id) BFF-->>Client: Role verification (Super Admin, Recruiter)
● Phase 2: Route Protection & SSR Loader Guard
sequenceDiagram autonumber participant User as Recruiter participant Client as TanStack Router participant BFF as SSR Server participant Admin as Firebase Admin User->>Client: Navigates to /dashboard/* Client->>BFF: Router beforeLoad -> getUserFn() alt No session / revoked BFF-->>Client: Redirect to /login else Session cookie valid BFF->>Admin: verifySessionCookie(checkRevoked=true) Admin-->>BFF: Decoded claims (UID, email) BFF->>Client: Return user context + prefetch role end
● Phase 3: Authenticated Request & IAM Delegation
sequenceDiagram autonumber participant Client as Browser Client participant BFF as TanStack BFF participant IAM as Google Cloud IAM participant Run as Cloud Run Microservice Client->>BFF: Server function (e.g. getJobsList) BFF->>BFF: isLoginMiddleware verifies session BFF->>IAM: GoogleAuth mints OIDC Token (aud: serviceUrl) IAM-->>BFF: Signed OIDC Bearer Token BFF->>Run: POST /api/v1/... [Bearer GCP_OIDC_TOKEN] Run->>Run: Verify token signature & roles/run.invoker Run-->>BFF: 200 OK + JSON domain payload BFF-->>Client: Typed domain response
● Phase 4: Session Invalidation & Logout
sequenceDiagram autonumber participant User as Recruiter participant Client as Browser Client participant BFF as TanStack BFF participant Auth as Firebase Client Auth User->>Client: Clicks Logout button Client->>BFF: logoutFn() BFF->>BFF: deleteCookie('session', { path: '/' }) BFF-->>Client: Set-Cookie: session (Max-Age=0) Client->>Auth: signOut() Client->>Client: queryClient.clear() (Purge cache) Client-->>User: Redirect to /_auth/login
